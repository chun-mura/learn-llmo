三つの役割

主要ベンダーはボットをだいたい三種に分けます。設定は独立です。

役割名前の例止めると
学習GPTBot, ClaudeBot, Google-Extended将来の学習（と、製品によってはアプリ側の接地）から外れる
検索インデックスOAI-SearchBot, Claude-SearchBot, PerplexityBot, Googlebotその製品の出典候補から外れる
ユーザー起動ChatGPT-User, Claude-User, Perplexity-User今この質問のためのライブ取得

学習だけ拒否して検索は許可する、が公式に想定されています。

OpenAI

  • OAI-SearchBot ChatGPT の検索回答に出す。拒否すると検索回答に出ない。ナビリンクは残る場合あり。反映は約 24 時間
  • GPTBot 基盤モデルの学習
  • ChatGPT-User ユーザー操作に応じた取得。robots.txt が適用されない場合がある。検索掲載の判定には使わない
User-agent: GPTBot
Disallow: /

User-agent: OAI-SearchBot
Allow: /

ChatGPT-User を拒否しても、robots.txt を見ない取得がありうると書いてあります。

Anthropic

ボット用途無効化すると
ClaudeBot学習になりうる収集今後の学習から外す合図
Claude-Userユーザー質問に応じた取得ユーザー起点の可視性が下がる
Claude-SearchBot検索用クロール検索インデックスから外れる

robots.txt と Crawl-delay を尊重する、CAPTCHA を迂回しない、IP ブロックは robots.txt が読めず不安定、と書いてあります。

OpenAI / Perplexity と違い、ユーザー起動の Claude-User も robots.txt で止められる、と書いてあります。ベンダー間で一致しません。

出典
  • Anthropic Help Center, crawler FAQ（更新表示 2026-04-07）

Perplexity

  • PerplexityBot 検索結果に出してリンクする。基盤モデル学習のためのクロールではない
  • Perplexity-User ユーザーの質問に応じてページを取る。学習用ではない。一般に robots.txt を無視する

WAF のボット一括拒否は、許可したつもりでも届きません。公式は User-Agent と公開 IP の両方を見ることを勧めています。

出典
  • Perplexity Crawlers ドキュメント
  • GEO 論文 §6（実世界エンジンとして Perplexity.ai）

Google

AI Overviews / AI Mode のクロール制御は Googlebot です。AI 機能だけ別ボット、ではありません。

適格条件: インデックスされ、スニペット付きで Search に出せること。追加の技術要件はありません。

Google-Extended は別物です。独立した User-Agent はなく、robots.txt のトークンだけを見ます。影響は Gemini アプリと Vertex の学習・接地です。Search の掲載や順位には使いません。

AI 面だけ止めたい場合は Search Console の生成 AI 制御です（第 8 課）。プレビューは nosnippet 系です。

作業例

方針: 学習には使われたくない。ChatGPT・Perplexity・Claude の回答には出てよい。Google Search（AI 含む）も出してよい。

User-agent: GPTBot
Disallow: /

User-agent: ClaudeBot
Disallow: /

User-agent: Google-Extended
Disallow: /

User-agent: OAI-SearchBot
Allow: /

User-agent: Claude-SearchBot
Allow: /

User-agent: PerplexityBot
Allow: /

Googlebot は触りません。Perplexity-User と ChatGPT-User は robots.txt だけでは止まらないことがあります。秘密のパスは認証と noindex です。

確認

  1. GPTBot だけ Disallow したサイトが ChatGPT search に出ない、は正しい推論か。
  2. Google-Extended を拒否したのに AI Overviews に出るのはバグか。
指針を見る

1. 誤りです。検索掲載は OAI-SearchBot です。

2. バグではありません。Google-Extended は Search に使いません。
